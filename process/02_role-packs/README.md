# Role Packs

Every role in an organization — Business Analyst, Architect, Product Manager, Security Lead, SRE — wants to benefit from agentic workflows.

Right now, mostly developers do.

That's because the tools that make agentic work powerful — Claude Code CLI, Copilot, MCP servers, custom skills, instruction files — are technical. They need configs, command lines, integrations. For anyone outside engineering, they're over the head.

Role packs try to close that gap. Each pack is a ready-to-use bundle that gives a non-developer role the same kind of agentic leverage developers already enjoy — without asking them to set up an MCP server or hand-write a CLAUDE.md.
